### 5. Data Types in Python

#### Numeric Data Types
- **Integers:** Whole numbers without decimal points
- **Floats:** Numbers with decimal points

**Important Note:** The instructor emphasized that division operations in Python always return float values, regardless of the operands. Assuming integer results from division can lead to programming errors.

#### Boolean Data Type
Logical operators in Python produce Boolean values (True or False). The instructor introduced the `type()` function as a tool for identifying and validating data types of variables.

#### String Data Type
The session covered three methods for defining strings in Python:
- Double quotes (`"text"`)
- Single quotes (`'text'`)
- Triple quotes (`"""text"""`)

Triple quotes, also known as doc strings, are particularly useful for multi-line strings and documentation. The class discussed practical applications, such as handling text containing apostrophes, where different quotation styles offer flexibility.

### 6. Functions Introduction

Functions were introduced as pre-written code operations designed to perform specific tasks. The instructor demonstrated:
- The `type()` function for identifying data types
- Proper syntax for function calls
- Order of operations when nesting functions

Students practiced using keyboard shortcuts to enclose expressions in brackets efficiently.

### 7. Variables and Assignment

#### Concept and Purpose
Using movie information as a relatable example, the instructor explained variables as named containers for storing and recalling information. The benefits of using variables include:
- **Reusability:** Values can be referenced multiple times without repetition
- **Flexibility:** Easy modification of values throughout code
- **Readability:** Meaningful variable names make code self-documenting
- **Maintainability:** Changes need to be made in only one location

#### Assignment Operator
The instructor clarified the distinction between:
- **Single equal sign (=):** Assignment operator for storing values in variables
- **Double equal sign (==):** Comparison operator for testing equality

Students learned that in assignment operations, the right-hand side (RHS) is evaluated first, and the result is then stored in the variable on the left-hand side (LHS).

#### Compound Assignment Operators
The session covered shorthand operators for updating variable values:
- **`+=`:** Addition assignment (equivalent to `variable = variable + value`)
- **`-=`:** Subtraction assignment (equivalent to `variable = variable - value`)

Students practiced declaring variables A, B, and C and performing various operations to understand these concepts practically.

### 8. Practical Applications and Efficiency

The instructor used the `print()` function to demonstrate displaying multiple operation results. A key exercise compared two approaches:
1. Hardcoding values directly into operations
2. Using variables to store and manipulate values

The class concluded that using variables significantly reduces manual errors and enhances code maintainability, as modifications require changes only to variable assignments rather than throughout the entire codebase. This principle was illustrated using a multiplication table example.

### 9. Introduction to Data Structures

#### Limitations of Individual Variables
The instructor demonstrated that using separate variables for related information (such as multiple movie details) becomes impractical as data volume increases. Each piece of information requires a unique variable name, leading to code that is difficult to manage and error-prone.

#### Lists as a Solution
Lists were introduced as efficient containers for storing multiple related values:
- A single list can hold multiple movie names, ratings, or other attributes
- Lists enable batch operations on all contained data
- Built-in functions like `sum()` and `len()` facilitate calculations such as computing average ratings

The instructor emphasized that data structures like lists are fundamental to writing scalable, maintainable code and encouraged students to think creatively about organizing information efficiently.
