Gaurav explained the concept of iterables in Python, emphasizing that a for loop can only run on collections of multiple values, such as strings, lists, tuples, and dictionaries, which are iterable. He clarified that integers and floats are not iterable because they represent single values, unlike a string, which can be broken down into individual letters. Gaurav also discussed the range function, which creates a collection of numbers, and demonstrated how to use the list function to display these values.
