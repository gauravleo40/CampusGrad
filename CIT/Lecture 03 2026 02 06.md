### 3. Loop Types and Applications

#### While Loops versus For Loops

The instructor led an in-depth discussion on the distinctions between loop types:

- **While Loops:** Used when the number of iterations is unknown, continuing until a specific condition is met
- **For Loops:** Used when the number of iterations is known in advance

### 7. Python Iterables

The instructor explained the concept of iterables in Python:

- For loops can only run on collections of multiple values
- Iterable types include strings, lists, tuples, and dictionaries
- Integers and floats are not iterable because they represent single values
- Strings are iterable because they can be broken down into individual characters

The range function was discussed as a method to create collections of numbers, with the list function demonstrated for displaying these values. This discussion aimed to reinforce fundamental concepts and prevent common errors in future coding tasks.
