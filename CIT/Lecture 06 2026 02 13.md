## Key topics covered

### 1. Python List Methods

The instructor covered several essential list manipulation methods:

**Remove and Pop Methods:**
- Demonstrated the difference between `remove()` (removes by value) and `pop()` (removes by index)
- Explained proper application of these methods on nested lists, emphasizing that `pop()` method can work for different Integer Index values
- Introduced a while loop solution for removing multiple occurrences of `NA` in a List

**Insert Method:**
- Demonstrated adding elements at specific index positions
- Assigned an exercise requiring students to insert total scores after each student's name in a marks list
- Emphasized the importance of understanding index-based operations versus value-based operations

**Extend Method:**
- Explained how to combine lists and overwrite existing data
- Provided examples of consolidating nested lists into single lists
- Demonstrated practical applications through a family wish list combination exercise

### 2. List Value Replacement Techniques

The instructor led an in-depth discussion on identifying and replacing specific values in lists:
- Explained the difference between indexing operations and index methods
- Demonstrated how to find values using the `index()` method
- Clarified that only numeric index values can be used within square brackets
- Showed how to replace values through indexing and assignment operations

### 3. Slicing and Advanced List Operations

Instructor demonstrated:
- Accessing and modifying elements in nested lists using slicing techniques
- Performing sum operations on list elements
- Breaking down complex problems into smaller, manageable steps
- The importance of understanding the logic behind each method

### 4. Conditional Statements

The session covered fundamental conditional programming concepts:
- Implementation of if-else constructs
- Example 01 : Printing even and odd numbers from a list using conditional logic
- Example 02 : Handling negative values by converting them to positive numbers without creating new lists

Students worked through overall 10 programming exercises throughout the session
