### 4. `break` and `continue` statement comparison

The session included an in-depth exploration of both `break` and `continue` statements:

- Both statements equires proper understanding of Python indentation for correct code block definition


**`break` Statement:**
- Exits the loop entirely when a specific condition is met
- Terminates all further loop iterations immediately

**`continue` Statement:**
- Skips remaining code in the current iteration only
- **Proceeds directly to the next iteration of the loop**
