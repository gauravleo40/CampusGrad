## Session Overview

The session focused on teaching participants to use Jupyter Notebooks to work in Python. Instructor guided attendees through **practical exercises covering dictionary creation, manipulation, and various operational methods**. The training emphasized **foundational concepts essential for future work with JSON files**.

---

## Key topics covered

### 1. Jupyter Notebooks local usage

Instructor provided comprehensive guidance on using Jupyter Notebooks in a local environment:

- **File Formats:** Explained the differences between .py and .ipynb file formats
- **Local Setup:** Demonstrated how to download and open notebooks locally using command prompt
- **Access Methods:** Showed two approaches to launching Jupyter Notebook:
  - Through Anaconda Navigator
  - Direct command line access
- **Industry Context:** Emphasized that local Jupyter Notebooks are commonly used in corporate environments due to data security requirements
- **Platform Differences:** Highlighted variations between local Jupyter Notebooks and Google Colab, including:
  - Absence of navigator section in local version
  - Different interface elements such as play buttons

### 2. Python dictionary operations

The session covered fundamental dictionary operations and best practices:

**Basic Concepts:**
- Recap of dictionary fundamentals
- Creating dictionaries from lists and tuples
- Requirement for paired lists (keys and values)

**Keyboard Shortcuts for Jupyter Notebook:**
- **A:** Add cell above
- **B:** Add cell below
- **X:** Delete cell

**Dictionary creation methods:**
- Using for loops
- Implementing conditional statements
- Leveraging the zip function for efficient dictionary creation
- Working with nested tuples and multiple data sources

**Best Practice:** When working with multiple data sources, using the zip function followed by the dict function is the preferred method for creating dictionaries.

### 3. Dictionary manipulation methods

Participants practiced various operations including:

- **Adding Items:** Using the `update` method
- **Removing Items:** Using the `pop` method
- **Checking Existence:** Verifying if items exist in dictionaries
- **Accessing Data:**
  - `values()` method for retrieving dictionary values
  - `items()` method for retrieving both keys and values
  - Direct key searches versus value operations

### 4. Advanced concepts introduced
- **Membership Operations:** Different approaches to searching dictionaries versus lists
- **Loop Operations:** Three different methods for running loops on dictionaries with `.keys()`, `.values()` and `.items()`

### 5. Programming best practices

Instructor emphasized several important practices:

- **Avoiding the use of Python keywords as variable names**
- Using the `help` function to explore dictionary methods independently
- Understanding how to restart a kernel when keywords are accidentally used
- The importance of hands-on practice and independent problem-solving
